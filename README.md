# Logbay 使用说明书

Logbay 是面向 Windows 的桌面设备工作台，用来同时管理 **Android** 与 **iOS** 设备。  
日常测试、排查线上问题、抓日志、装包、看屏幕，都可以在一个窗口里完成，不必再单独开 Android Studio、命令行或一堆零散工具。

官方仓库：[https://github.com/liuziyang-hub/Logbay](https://github.com/liuziyang-hub/Logbay)

## 1. 能做什么

| 能力 | 说明 |
|------|------|
| **实时日志** | 查看 Android logcat / iOS syslog，支持过滤、搜索、多标签、导出 |
| **打开本地日志** | 无设备时也可导入已保存的 logcat / syslog 文件离线查看 |
| **屏幕镜像** | 在电脑上查看并操作 Android 设备画面（依赖 USB 调试） |
| **文件浏览** | 浏览设备存储，上传、下载文件 |
| **应用管理** | 查看已安装应用；安装 APK / IPA（支持拖放到窗口） |
| **内置终端** | Android 设备可直接打开 ADB Shell，无需另开命令行 |
| **无线调试** | Android 支持 Wi‑Fi ADB 连接 |
| **多设备** | 可同时连接多台设备，各自独立标签与面板 |
| **设备主页** | 电池 / CPU / 内存仪表，硬件、软件、连接状态一览 |

## 2. 运行环境

### 电脑

- 操作系统：**Windows 10 / 11（64 位）** 推荐
- 建议预留足够磁盘空间（主题视频与运行库会占用一定空间）

### Android 设备

1. 手机开启 **开发者选项** → 打开 **USB 调试**
2. 用数据线连接电脑，手机上弹出「允许 USB 调试」时点 **允许**
3. 首次连接建议勾选「始终允许这台计算机」

> Logbay 已内置常用调试工具组件，同事一般 **不必单独安装 Android SDK**。若本机已装过 `adb` 也可正常共存。

### iOS 设备

1. 电脑安装 **[Apple 官方 iTunes](https://www.apple.com/itunes/)**（或 Apple Devices），以获得设备驱动  
   - 请优先用官网安装包，**不要用微软商店版 iTunes**（驱动常不完整）
2. 用数据线连接 iPhone / iPad
3. 手机上点 **信任此电脑**，并按提示输入锁屏密码

## 3. 安装与启动

### 方式一：安装包（推荐发给同事）

1. 收到 `Logbay-*-windows-setup.exe`
2. 双击运行安装向导
3. 按提示完成安装（默认安装到「Program Files」下的 Logbay 目录）
4. 可勾选创建桌面快捷方式
5. 安装结束后可直接启动 Logbay

### 方式二：便携目录

若拿到的是完整 `Release` 文件夹（内含 `eagly.exe` 与 `data` 等）：

1. 解压到任意目录（路径尽量不要含特殊字符）
2. 双击 `eagly.exe` 或项目提供的 `lzy.exe` 启动  
3. **不要只拷贝单个 exe**，必须连同同目录下的 `data` 等文件一起带走

### 防火墙 / 杀软提示

首次启动若被 Windows SmartScreen 或杀软拦截：选「更多信息」→「仍要运行」。  
这是未做商业代码签名时的常见提示，与功能本身无关。

## 4. 第一次连接设备

### Android（USB）

1. 打开 Logbay  
2. 在主页点击 **加载设备**（或插线后点顶栏刷新）  
3. 在「选择设备」列表中应看到你的机型与「在线」状态  
4. 点击该设备，进入设备工作区（顶栏会出现设备标签页）

### Android（无线）

见下文 [无线 ADB](#12-无线-adbandroid)。

### iOS

1. 确认已安装官网版 iTunes / Apple Devices，且手机已「信任」电脑  
2. 打开 Logbay → **加载设备**  
3. 列表中出现设备后点击进入  

若列表为空：拔插数据线、重新点「信任」、重启 Logbay 后再点 **加载设备**。

## 5. 界面总览

### 顶栏

- **品牌 / 产品名**：左侧显示 Logbay  
- **标签页**：每个已打开的设备工作区一个标签；也可打开「导入的日志」等无设备工作区  
- **刷新**：重新扫描已连接设备  
- **无线 / 投屏相关入口**：快速进入无线调试等能力  
- **GitHub**：一键打开官方仓库  
- **设置**：主题、外观等

### 设备侧栏（连接设备后）

从上到下常见入口：

| 入口 | 作用 |
|------|------|
| **主页** | 设备概览：电量、CPU、内存、硬件/软件/连接信息 |
| **日志** | 实时日志与过滤 |
| **终端** | ADB Shell（仅 Android） |
| **镜像** | 屏幕镜像（仅 Android） |
| **崩溃** | 崩溃报告（iOS 等场景） |
| **文件** | 文件管理 |
| **应用** | 已安装应用列表 |
| **安装** | 安装包安装入口 |
| **设置** | 应用设置 |

> 设备信息以 **主页** 为准集中展示，无需再找单独的「详情」页。

### 落地主页（未选设备时）

左侧为品牌与氛围背景；右侧为：

- **选择设备**：加载设备、无线 ADB、已发现设备列表  
- **打开日志文件**：导入本地日志，并显示最近打开的文件

## 6. 设备主页

进入设备后默认可打开 **主页**，用于一眼看懂当前机器状态：

- **快捷入口**：日志 / 镜像 / 文件 / 应用  
- **实时仪表**：电池、CPU、内存（颜色随主题主色 / 辅色 / 点缀色区分）  
- **信息卡片**：显示、硬件、软件与区域、连接（USB / Wi‑Fi / 蓝牙等）、最近安装  

适合：开工前确认「设备在线、调试开了、电量够不够、刚才装了什么包」。

## 7. 日志

### 实时日志

1. 选中设备 → 侧栏点 **日志**（或主页快捷入口）  
2. 日志开始滚动后，可用过滤栏按级别、标记、关键字筛选  
3. 支持多标签：同一台设备可开多个日志视图，互不干扰  

### 常用技巧

- **隐藏不常用列**：在列设置里关掉暂时不需要的列，表格更干净  
- **精确 / 正则 / 否定过滤**：需要精准排查时切换匹配方式  
- **仅显示最近几分钟**：缩小时间窗口，减少刷屏  
- **字号**：可快速调大调小，长时间盯日志更舒服  
- **导出 / 复制**：需要贴到工单或发给同事时，导出或复制选中行  

术语对照（Android）：

| 界面 | 含义 |
|------|------|
| 时间戳 | 日志时间 |
| 软件包 | 进程 / 包相关列 |
| 优先级 | Verbose / Debug / Info / Warn / Error 等 |
| 标记 | Tag |
| 消息 | 正文 |

### 打开已保存的日志文件

1. 回到落地页 → **导入日志文件**  
2. 选择本机 `.log` / `.txt` 等文件  
3. 可在无设备情况下离线分析  

也可将文件拖入窗口（视当前页面支持情况）。

## 8. 终端

仅 **已连接的 Android** 可用。

1. 侧栏点 **终端**  
2. 进入设备 Shell 后，可执行常见调试命令（如查看属性、目录、简单排查）  
3. 不需要再单独开 `cmd` / PowerShell 敲 `adb shell`

注意：危险命令（删数据、改系统属性等）请自行评估风险。

---

## 9. 屏幕镜像

仅 **Android**，且需 USB 调试可用。

1. 侧栏点 **镜像**（或主页「镜像」）  
2. 等待画面出现后，可在电脑上观察复现路径，同时开日志面板对照  

适合：一边操作 App 复现，一边看 logcat 报错。

若黑屏 / 启动失败：确认 USB 调试仍授权、换线或换口、关闭手机省电限制后再试。

---

## 10. 文件管理

1. 侧栏点 **文件**  
2. 浏览目录，进行上传、下载等操作  
3. 权限不足的系统目录可能无法访问（与设备权限策略有关）

---

## 11. 应用管理与安装

### 查看已安装应用

侧栏 **应用** → 浏览列表，可按需卸载或查看信息（以界面实际操作为准）。

### 安装应用

支持多种方式：

1. 主页或顶栏 **安装应用**  
2. 侧栏 **安装**  
3. **直接把 `.apk` / `.ipa` 拖到 Logbay 窗口**（最省事）

安装成功后，主页「最近安装」里通常能看到新记录。

## 12. 无线 ADB（Android）

适合：设备需要离开线缆、长时间抓日志。

典型流程（具体按钮以界面为准）：

1. 先用 USB 连接并完成一次授权  
2. 在主页点 **无线 ADB**，按提示开启无线调试 / 配对  
3. 配对成功后可拔掉数据线，继续在 Logbay 中使用  

若断开：回到有线连接重新配对，或检查手机与电脑是否在同一局域网。

## 13. 多设备并行

Logbay 支持 **同时连接多台** Android / iOS 设备：

- 每台设备在顶栏有独立标签  
- 各自可打开日志、文件、应用等面板，互不影响  
- 适合：对照两台机复现、一台出日志一台对照 UI  

操作建议：先全部点「加载设备」确认列表都在线，再分别点进各设备标签工作。

## 16. 常见问题

### 设备列表是空的

- Android：是否打开 USB 调试并点了「允许」？换线 / 换口再试  
- iOS：是否安装官网 iTunes？是否点了「信任」？  
- 点顶栏刷新或主页 **加载设备**  

### 日志不刷 / 一直转圈

- 确认设备仍显示「在线」  
- 关闭再打开「日志」面板  
- Android 可在终端执行 `logcat -c` 后重开日志（注意会清缓冲）  

### 镜像打不开

- 仅 Android 支持  
- 确认 USB 调试有效；部分厂商需关闭「仅充电」模式  

### 安装包失败

- APK：确认架构匹配（如 arm64）、是否需要先卸载旧包  
- IPA：需符合当前 iOS 侧安装工具能力与签名条件  

### 杀软报毒 / SmartScreen 拦截

- 选「仍要运行」；如公司策略严格，可将安装包加入白名单  

### 程序闪退

- 把复现步骤、系统版本、是否接了哪台设备，反馈到 GitHub Issues

## 17. 开发者构建

适合要改代码、自己出包的同学。

```bash
# 需要本机 Flutter SDK
flutter pub get
flutter run -d windows
```

发布构建：

```bash
flutter build windows --release
```

输出目录：`build/windows/x64/runner/Release/`。

Windows 开发还需 Visual Studio 的「使用 C++ 的桌面开发」工作负载。更完整的环境说明见仓库内 `docs/SETUP.md`。

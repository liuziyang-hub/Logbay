# Logbay 1.5.7

## 镜像显示

- 虚拟显示驱动兼容模式的 Android 镜像现已嵌入 Logbay 镜像面板。
- 保留官方 scrcpy 独立进程，画面不经过此前发生崩溃的 Flutter 视频纹理链路。
- 画面跟随面板尺寸、Windows 缩放比例和手机横竖屏调整。
- 切换页面、关闭面板及打开弹窗时隐藏原生画面，返回后恢复。
- 点击、滑动和键盘输入由 scrcpy 直接接收。

## 验证

- Windows 正式构建和镜像相关回归测试。
- Pixel 7 Pro USB 真机验证内嵌显示、点击、滑动、页面切换。

可直接覆盖安装。1.5.6 用户可通过应用内更新入口下载并启动覆盖安装；Windows 仍可能要求确认管理员权限。
